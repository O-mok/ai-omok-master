## 단계별 개발 지시 시나리오 (AI 에이전트용)

* **Step 1:** "15x15 그리드의 오목 게임을 단일 HTML/JS/CSS로 구현하라. 흑/백 교대 착수와 5목 승패 판정 로직만 포함해라."
* **Step 2:** "게임 종료 후 누적된 기보 배열을 OpenRouter API로 전송하는 기능을 `app.js`에 추가하라. 환경 변수 대신 코드 내 임시 변수로 API 키를 받고, 위에 정의된 시스템 프롬프트를 사용하여 반드시 JSON 형태로 응답받도록 하라."
* **Step 3:** "API에서 반환받은 JSON의 `eval` 값에 따라 바둑판 위 돌에 점(Dot)을 추가하고, `criticalTurns`에 해당하는 돌에는 CSS 깜빡임 효과를 적용하라. 특정 돌을 클릭하면 `comment`가 화면 하단에 표시되게 하라. API 호출 중에는 직관적인 로딩 스피너 UI를 띄우고, JSON 파싱 실패 시 예외 처리 로직을 추가하라."
