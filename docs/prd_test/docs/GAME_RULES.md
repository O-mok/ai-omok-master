# GAME_RULES — 오목 규칙 (이 프로젝트의 기준 문서)

> 규칙 해석이 갈릴 수 있는 부분은 모두 이 문서의 기준을 따른다.
> 구현·테스트·AI 해설에서 규칙이 헷갈리면 **이 문서가 정답**이다. (검증 가이드라인 1번)

---

## 1. 기본 설정

- 판: **15 × 15** 교점 (바둑판 격자의 교점에 돌을 놓는다).
- 돌: **흑(선공)** 과 **백(후공)** 이 번갈아 한 수씩 둔다.
- 한 번 놓은 돌은 **움직이거나 제거할 수 없다.** (무르기는 옵션, 아래 §7)
- 이미 돌이 있는 교점, 판 밖의 교점에는 둘 수 없다.
- 첫 수는 자유(AI가 흑일 때는 중앙 천원 `H8`).

## 2. 승리 — 기본 규칙(자유룰, `ruleset: "free"`)

- 자기 돌을 **가로 · 세로 · 대각선(↘, ↗) 중 한 방향으로 연속 5개 이상** 만들면 즉시 승리한다.
- **6목 이상(장목)도 승리**로 인정한다. (흑·백 동일)
- 연속은 **같은 색 돌이 빈칸 없이 이어진 것**만 인정한다. 상대 돌이나 빈칸이 끼면 끊긴 것이다.
- 승리 판정은 **방금 둔 돌을 기준으로 4개 방향만** 확인한다. (전체 판 스캔 금지 — 성능·오류 방지)

## 3. 무승부

- 225개 교점이 모두 차고 승자가 없으면 무승부.

## 4. 기권

- 대국 중 언제든 기권할 수 있다. 기권한 쪽이 패배, 결과 사유는 `resign`.
- 기권으로 끝난 대국도 복기할 수 있다(마지막 국면까지 분석).

## 5. 좌표계 (구현 필수 준수)

| 항목 | 정의 |
|---|---|
| 내부 좌표 | `(x, y)`, **0-index**, 원점은 **좌상단**. `x`=열(→), `y`=행(↓). 범위 0~14. |
| 표시 라벨 | 열 `A`~`O`(= x 0~14, `I` 포함), 행 `1`~`15`(= y+1, **위에서 아래로**). 예: `(7,7)` → `H8`, `(0,0)` → `A1`, `(14,14)` → `O15`. |
| 수 번호 | **1-index**. 홀수 수 = 흑, 짝수 수 = 백. |
| 변환 | `toLabel(x,y)` / `fromLabel("H8")` **단 하나의 모듈**(`engine/board.js`)에서만 변환한다. 다른 곳에서 문자열 조립 금지. |
| 화점(성점) | `(3,3) (11,3) (7,7) (3,11) (11,11)` — 보드에 점으로 표시. |

> 표준 렌주 표기는 행 번호가 아래에서 위로 증가하지만, 이 프로젝트는 구현 오류를 줄이기 위해 **위에서 아래**로 통일한다.

## 6. 렌주룰 옵션 (`ruleset: "renju"`) — 우선순위 P2

흑이 너무 유리한 점을 보정하는 대회용 규칙. **흑에게만** 금수가 적용된다.

| 금수 | 정의 |
|---|---|
| **삼삼(3-3)** | 한 수로 **열린 3**이 동시에 2개 이상 생기는 자리 |
| **사사(4-4)** | 한 수로 **4**가 동시에 2개 이상 생기는 자리 (한 줄에 4가 2개 생기는 경우 포함) |
| **장목(overline)** | 한 수로 **6목 이상**이 되는 자리 |

- 렌주룰에서 **흑은 "정확히 5목"일 때만 승리**한다(6목 이상은 승리 아님·금수). **백은 5목 이상이면 승리**한다.
- 흑이 금수 자리에 두려 하면 **착수를 막고** "금수" 안내를 표시한다. (AI 흑도 금수 자리를 피한다.)
- **정확히 5목이 완성되는 수는 삼삼·사사와 겹쳐도 승리**한다(5목 우선).
- ⚠️ **엣지 케이스(구현 시 반드시 테스트로 고정):** ① 열린 3을 만드는 "완성 자리"가 그 자체로 금수이면 그 3은 열린 3으로 세지 않는다(재귀 판정) ② 장목과 정확한 5목이 같은 수에서 동시에 생기는 경우 ③ 막힌 3(한쪽이 막힘)은 삼삼에 포함되지 않는다. 판정이 애매하면 공식 렌주 규정을 다시 확인하고, 결정한 해석을 `tests/rules.test.js`의 케이스 이름에 남긴다.
- 렌주룰은 **옵션 토글**이며, 기본값은 항상 자유룰이다.

## 7. 무르기 (옵션, P2)

- PvE에서만: 내 마지막 수와 AI의 응수, **2수를 함께 취소**. 대국당 최대 3회.
- 취소된 수는 기보에서 **완전히 제거**한다(복기에는 최종 수순만 남는다).
- PvP에서는 제공하지 않는다.

## 8. 용어 (엔진 태그·AI 해설 공통)

| 용어 | 정의 |
|---|---|
| 2 / 3 / 4 | 같은 색 돌이 한 줄에 2·3·4개 이어지고 5목 완성 가능성이 남아 있는 형태 |
| **열린 3 (활삼)** | 한 수를 더 두면 **열린 4**가 될 수 있는 3 (양끝이 비어 있고 확장 공간이 충분) |
| **막힌 3** | 한쪽이 막혀 열린 4가 될 수 없는 3 |
| **열린 4 (활사)** | 양쪽 모두 5목을 완성할 수 있는 4 → 사실상 승리 확정 |
| **막힌 4 (사)** | 한쪽으로만 5목 완성이 가능한 4 → 상대가 즉시 막아야 함 |
| **4-3** | 한 수로 4와 열린 3을 동시에 만드는 수 → 대개 승리 확정 |
| **쌍삼** | 한 수로 열린 3을 2개 만드는 수 (자유룰에서는 강력한 공격, 렌주룰 흑에는 금수) |
| **필수 방어** | 상대가 다음 수에 5목을 만들 수 있어 반드시 막아야 하는 상황 |
| **놓친 승리** | 내가 5목(또는 승리가 확정되는 수)을 둘 수 있었는데 두지 않은 것 |

## 9. 이 서비스에서 명시한 해석 (모호성 제거)

1. 기본 규칙은 **자유룰**: 흑·백 모두 5목 이상 승리, 금수 없음.
2. 승리 5목 하이라이트는 **방금 둔 돌을 포함한 연속 구간**을 표시한다(6목 이상이면 전체 구간).
3. 한 수로 두 줄에서 동시에 5목이 완성되어도 승리는 1회로 처리한다.
4. 마지막 수에서 판이 가득 차고 동시에 5목이 완성되면 **승리가 우선**한다(무승부 아님).
5. 대국 종료 후에는 더 이상 착수할 수 없다.
