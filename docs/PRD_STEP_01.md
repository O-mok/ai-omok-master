# PRD Step 1 — 렌주룰 오목 코어 (엔진 + 보드 UI)

## 서비스 기획 (5W1H)
| | |
|---|---|
| Why | 오목은 승패만 남고 "왜 졌는지"가 남지 않는다. AI로 수순별 복기를 제공하는 시연용 서비스를 만든다 |
| Who | 오목을 아는 일반 사용자, 발표 청중 |
| What | 렌주룰 오목(AI/2인 대국) + 종료 후 AI 수순 평가·핵심 수 하이라이트 |
| When | 대국 직후 복기, 시연 중 5분 안에 1판 |
| Where | 데스크톱·모바일 브라우저. `npm run dev` |
| How | React(Vite) 클라이언트 전용. 규칙은 `src/engine/omok.ts`. OpenRouter는 Step 2에서 브라우저 직접 호출 |

## 범위
- 15×15 보드, 클릭 착수, 흑 선공, 기보 `[{n,x,y,player}]` 누적
- 모드: AI 대국 / 2인 대국. AI 난이도 선택 UI(동작은 Step 2)
- 렌주룰: 흑 금수 = 삼삼·사사·장목 → 착수 차단 + 사유 표시. 백은 제한 없음
- 승리: 흑 정확히 5목, 백 5목 이상. 판이 가득 차면 무승부
