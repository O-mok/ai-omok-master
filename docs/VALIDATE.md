# 검증 가이드라인

CLAUDE.md의 "오목 로직 교차 검증 가이드라인"을 실행할 때 이 체크리스트를 따른다.

## 엔진 (`npm test`)
- [ ] 중복·판 밖 착수 거부
- [ ] 흑 장목 금수, 흑 정확 5목은 금수 아님(승리)
- [ ] 교차 삼삼, 교차 사사
- [ ] 같은 줄 사사 `●.●●●.●` (열린 4는 사사가 아님)
- [ ] 백 6목은 금수 없이 승리
- [ ] `reset()` 후 기보·승자·흑 선공 초기화

새 의심 케이스가 있으면 **수정 전에** `src/engine/omok.test.ts`에 시나리오를 추가한다.

## OpenRouter (수동)
1. UI에 키를 넣고 **연결 테스트** 버튼이 성공하는지 확인.
2. 짧은 대국(normal/hard)에서 AI 수가 빈 칸·0~14인지, 실패 시에도 수가 놓이는지.
3. 대국 종료 후 자동 분석이 동작하는지 확인.
4. 분석 JSON이 정규화되는지(없는 수 번호, 점유 칸 best 제거).
5. 키를 지우고 대국이 휴리스틱으로 계속되는지.

실패 시 모델 ID를 다른 `:free` 모델로 바꾸고 재시도한다. 기본값은 `openrouter/free`.
