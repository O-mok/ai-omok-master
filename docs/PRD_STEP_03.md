# PRD Step 3 — 복기 뷰어 · 핵심 수 하이라이트 · 검증

## 기능
- 결과 화면: 승자, AI 총평, 슬라이더/처음·이전·다음·끝, 수순 칩(색=평가, 굵은 테두리=핵심 수)
- "핵심 수만 보기" 필터. 칩 클릭 시 해당 수까지 보드 재현 + 코멘트 + 더 나은 수(파란 링)
- 엔진 사실 우선: 총평 앞에 엔진 승패를 두고, 범위 밖/점유 칸 `best`는 제거
- 폴백: API 실패 시 로컬 요약(총 수·승자)으로 대체
- 모바일: 820px 이하 1열 레이아웃
- 엔진 보강: 같은 줄 사사를 5칸 창문의 서로 다른 빈 칸 수로 센다 (`docs/PRD_STEP_01.md` 한계 해소)
